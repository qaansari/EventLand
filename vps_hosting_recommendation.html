2. Architectural Sizing: Why 4 GB Fails & 8 GB Excels on Windows

EventLand is a concurrent event ticketing engine featuring real-time seat holds via SignalR WebSockets, background booking expiry workers, automated image compression, and an MSSQL relational database. Deploying both backend and frontend on a single Windows Server requires realistic memory planning:

Stack Component Technology Idle / Base RAM Active Spike Load
Operating System Windows Server 2022 (Desktop/RDP) ~2,200 MB ~2,500 MB (with active RDP session)
Database Server Microsoft SQL Server 2022 Express ~1,500 MB ~2,000 MB (buffer cache for seating/holds)
Backend API & Hub .NET 10 Web API + SignalR Hub ~350 MB ~600 MB (concurrent WebSocket holds & auth)
Cache Engine Redis / Memurai on Windows ~120 MB ~200 MB (atomic 30-min seat reservation keys)
Frontend Web App React 18 + Vite SPA on IIS ~50 MB ~100 MB (static HTTP/2 + Brotli compression)
TOTAL BASELINE MEMORY NEEDED ~4,220 MB (4.2 GB) ~5,400 MB (5.4 GB Peak)

❌ 4 GB RAM (Current Link) — Crash Risk

Physical RAM is exhausted on boot. Windows initiates aggressive SSD disk thrashing (paging). Results: RDP session freezes, SignalR WebSocket drops, and MSSQL crashes with Out-Of-Memory (OOM) errors during customer checkouts.

✅ 8 GB RAM (WinVPS4) — Recommended

Leaves ~2.6 to 3.5 GB of free headroom. MSSQL buffer pool operates at full speed, SignalR broadcasts instantaneous seat hold updates across all users, and Remote Desktop administrative access remains buttery smooth.

Phase 2: Deploying Frontend & Backend

  • 6
    DNS Setup: In your domain registrar, add two A Records pointing to your VPS Static IP: @ → VPS_IP and www → VPS_IP.
  • 7
    Connect via RDP: Open Remote Desktop Connection (mstsc), enter VPS IP, username Administrator, and password.
  • 8
    Install Runtimes: Install (a) .NET 10 Windows Hosting Bundle, (b) SQL Server 2022 Express & SSMS, (c) Memurai/Redis.
  • 9
    Deploy Application: Place compiled React SPA in C:\inetpub\wwwroot\eventland and .NET API in C:\inetpub\eventland-api. Execute API once to run migration 20260909105956_InitialCreate.
  • 10
    Bind SSL: Run Win-ACME command line, select your IIS site, and Let's Encrypt will bind automated HTTPS with zero maintenance.
