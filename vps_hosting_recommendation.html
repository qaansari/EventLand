1. Executive Summary & Application Technical Demands

Event Land is an enterprise-grade live ticketing platform built with high concurrency, real-time interactive seating holds, and financial proof verification. Running the system smoothly requires matching the server infrastructure to its core components:

2. Memory Sizing: Why 4 GB RAM Fails & 12 GB RAM Succeeds

Critical Sizing Warning for Windows Server: Windows Server with GUI and Remote Desktop (RDP) uses ~2.2 GB RAM idle. Microsoft SQL Server requires at least 2.0 GB RAM. On a 4 GB VPS (Micro plan), total baseline memory consumption exceeds 100% immediately on boot, triggering virtual memory disk thrashing, unresponsive RDP, and frequent SQL Server crash out-of-memory errors.

❌ MICRO Plan (4 GB RAM) - High Risk

  • Windows Server OS: ~2.2 GB
  • Microsoft SQL Server: ~2.0 GB
  • .NET 10 API & Kestrel: ~0.4 GB
  • Total Base Load: ~4.6 GB (Exceeds Physical RAM)
  • Result: Heavy disk paging, laggy RDP, ticket booking crashes.

✅ MINI Plan (12 GB RAM) - Recommended

  • Windows Server OS: ~2.5 GB
  • Microsoft SQL Server: ~4.0 GB (Generous query buffer)
  • .NET 10 API + SignalR: ~0.6 GB
  • Free Headroom: ~5.0 GB available for burst traffic
  • Result: Blazing fast ticket booking, responsive RDP, zero lag.

  • 3

  • 4

Phase 2: Connecting Domain & Deploying Stack

  • 5
    Map DNS: In your domain registrar's DNS panel, create two A Records pointing to your new VPS Static IP: @ → VPS_IP and www → VPS_IP.
  • 6
    Connect via RDP: On your computer, open Remote Desktop Connection (mstsc), enter your VPS IP, username Administrator, and password.
  • 7
    Install Software: Download and install: (1) .NET 10 Windows Hosting Bundle, (2) SQL Server 2022 Express, (3) SSMS.
  • 8
    Deploy Backend & Frontend: Copy published EventLand.Api and React dist/ folder to C:\inetpub\wwwroot\eventland. Run the API executable once to auto-seed database schema via migration 20260909105956_InitialCreate.
  • 9
    Install HTTPS: Run Win-ACME command line, select your IIS site, and it automatically binds and auto-renews your Let's Encrypt SSL certificate.
